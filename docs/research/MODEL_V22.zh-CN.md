# MDT 执行契约与层级小型 Agent 闭环调控模型

论文研究详述与发表证据计划 | Version 2.2 | 2026-09-19

依据用户提供的 v2.2 发表路线重构附件优化，保留 v2.1 已纠正的执行语义和代码。当前范围为公开数据与仿真，睡前放松为应用场景。执行契约是主贡献；层级收益是探索性问题；人体效果与执行算子离线评估分别构成独立后续路线。2026-09-19 的工作区审计未发现合格自然运行日志：M0 为 not_assessable，发生率及区间未测。本文是研究设计档案，不是已完成实验的投稿稿。



## 文档定位与摘要

本文研究学习建议与实际执行之间的契约：当观测、推理与音乐边界异步发生时，怎样使每个提交和确认都能追溯其观测依据、权限、绝对目标与失效处理？系统保留“1 个会话总协调器、3 个领域协调器、5 个专职 Agent”的闭环实现，但不把层级树本身作为主创新。Agent 提交有限建议，单写入网关在实际边界校验双 TTL、epoch、命令幂等与硬约束，并严格区分建议、提交和 ACK。

本版把论文路线分为三个独立证据任务。论文一聚焦执行契约及公平强基线下的机制与代价；论文二在未来获批人体研究中评价真实效果；论文三作为有条件候选，研究版本化执行机制对离线策略评估的影响。静态动作边缘化、裁剪动作混合测度及一般无重叠部分识别已有文献，本方案不重复宣称这些内容的新颖性。

论文一新增 M0 自然运行日志审计作为现实问题前提的证据门，并将故障来源分为 F1 真实记录、F2 外部来源、F3 构造压力场景。当前仅发现合成演示、回归工件和软件测试，不能用于真实发生率估计。M0 不可评估不等于失效罕见；当前仍可完成公开数据感知验证、仿真控制和机制测试，但论文主张必须限定为该证据范围。

既有 v2.1 控制细节继续成立：双独立估计、A3 一次锁存、独立 PI 分支、分用途权限门、绝对音乐目标与有限 HOLD；首版 A5 冻结规则。可归因执行不等于因果疗效识别，参数限幅、软件测试通过及分层组织不构成人体安全或稳定性证明。

**关键词：** physiological feedback；hierarchical agents；adaptive music；uncertainty-aware control；runtime monitoring；personalization。

### English working abstract

We study execution contracts for learning-enabled physiological-feedback music regulation. A hierarchical compact-agent implementation preserves the closed loop while a single gateway separates proposals, accepted targets, submitted commands, and acknowledged actions. Temporal validity, bounded authority, absolute targets, and stop semantics define the execution interface. The primary evaluation compares explicit contracts against a strong common-practice baseline under shared models, constraints, and external auditing; additional hierarchy effects are exploratory. A provenance-aware protocol distinguishes naturally observed failures, externally documented scenarios, and constructed stress tests. No eligible natural execution logs were found in the current workspace, so real-world failure prevalence remains unassessed. Public physiological recordings and reactive simulations support component and mechanism studies, not clinical sleep claims. We separately outline future human evaluation and a conditional research route on off-policy evaluation under changing execution operators. Known action marginalization, mixed-measure importance sampling, and general partial-identification results are treated as prior work. This dossier specifies implementation, falsifiable comparisons, evidence gates, and publication boundaries; it reports no unperformed empirical study.

# 01 研究定位：论文究竟要回答什么

## 1.1 从功能清单转向可检验的研究问题

原方案已经说明“有哪些模块、模块如何连接”，但高质量论文还需回答：为什么这些边界是必要的；同样的模型放在扁平系统里是否也能取得相同效果；在什么条件下层级组织改善可靠性，又付出多少时延和复杂度；生理反馈的变化能否归因于系统干预。论文应围绕这些问题构建证据，而不是把每个模块都包装成独立创新。

主要研究问题是：在冻结模型、硬守卫和资源预算后，显式执行契约相对强 common-practice 实现，能否减少按共同外部规则定义的非法执行，同时保持覆盖、控制质量与时延？合理的裁剪、拒绝和延迟执行本身不是失败。只有实际违反冻结的执行要求，或把未知执行误判为确定状态，才属于相应失效事件。

层级组织的额外收益与学习模块的增益另行评估。H 对 B2 的组织比较不再承担题目中的主张；若同契约扁平实现同样有效，应如实报告。

## 1.2 前提、主要假设与探索性问题

为避免编号混淆，附件 H0 在本文称为 P0（经验前提，不是统计零假设）；附件探索性 E1 称为 E_hier，原数据实验 E1/E2/E3 保留原编号。

| 标记 | 问题与支持证据 | 不支持与未判断的区别 |
| --- | --- | --- |
| P0（附件 H0） | 真实自然运行中存在预先定义、不可忽略的执行失效；由 M0 审计判断 | 无日志为不可评估；区间跨阈值为不确定；所有上界低于阈值才支持低频 |
| H1（主要） | B2 相对强 B1 在声明故障来源内改善共同定义的执行终点，并满足覆盖与代价界值 | CI 跨零或率比跨 1 是证据不足；精确排除最小收益或支持反向效应另报 |
| H3（次要） | A2 的真实公开感知误差、A3/A4 的仿真调控指标分别改善 | 真实感知与仿真控制不得合并为人体个体化效果 |
| E_hier（探索） | H 相对同契约 B2 是否额外改善故障隔离、定位或维护成本 | 不预设层级获胜；非劣效失败不自动证明劣效；不得事后提升为主要终点 |

主贡献为执行契约；紧凑模型和层级组织是实现载体；公开数据、来源分层的故障库和可复现工件是证据支撑。H1 的结论必须带来源限定：F3 上成功仅说明构造条件下的机制作用，不能外推真实收益或自然失效率。

## 1.3 “Agent”的操作性定义

本文中的 Agent 是具有局部职责、有限内部状态、受限动作空间和结构化接口的软件决策单元。A2、A3、A4、A5 具有学习接口；本轮实验只要求 A2 的公开数据模型与 A3/A4 的仿真模型，A5 使用冻结规则。A1 和 C0-C3 为确定性规则或状态机。九个角色可以部署在同一个受控进程中；角色数量不等于模型数、线程数或服务数。

这里没有在线多 Agent 强化学习，也没有语言模型之间的自由协商。A3 中“hierarchical bandit”指群体与个体参数的统计部分池化；它与组织层级 C0-C3/A1-A5 是两个不同概念。论文题目若使用 multi-agent，应在方法开始就给出上述定义，并补充模块化控制系统作为公平比较对象。

# 02 相关工作与可辩护的创新边界

## 2.1 闭环音乐调节并非空白领域

Ho 与 Chen 的 iHeartLift 已使用 HRV 与音乐节奏变化构成反馈机制 [1]；Ehrlich 等提出基于脑信号与算法音乐生成的闭环情绪反馈系统 [2]。因此，本项目不能将“根据生理信号调音乐”作为首创。与这些系统比较时，应具体讨论传感模态、调控目标、反馈变量、音乐动作空间与验证方式。

2026 年的 MindMelody 预印本进一步结合 EEG 情绪推断、LLM 计划与层级音乐控制 [3]。它说明“闭环 + 层级 + 个体化”这一宽泛组合也不足以界定新颖性。本文可探索的区别是紧凑数值模型、确定性权限收缩、异步执行语义和可复现的故障隔离实验。这些只是基于已检索材料的定位，不能代替投稿前更完整的相关工作检索。

## 2.2 方法维度的比较框架

| 文献 / 技术方向 | 与本研究的联系 | 应保留的区别与限制 |
| --- | --- | --- |
| iHeartLift [1] | HRV 驱动的音乐反馈 | 不以闭环概念作为本项目新颖性 |
| Music-based BCI [2] | 可参数化音乐与情绪反馈 | EEG 与 EDA/HRV 的观测语义不同 |
| MindMelody [3] | 个体化闭环、层级控制 | 预印本；生成式框架与本项目动作空间不同 |
| TCA / MDS [4,5] | 任务分解、监测、状态与命令分离 | 借鉴组织原则，不宣称发明层级协调 |
| Runtime assurance [6] | 高性能模块与执行监视分离 | 未识别用户动力学时，不直接获得其安全保证 |
| 校准与离线策略评估 [7-9] | 不确定性、行为概率、评估偏差 | 前提需逐项满足，不能仅记录 logprob 即宣称有效 |

## 2.3 应避免的五类论文表述

不写“首个基于多 Agent 的安全音乐治疗系统”，因为首创性、临床疗效与安全性都尚无充分证据。不写“Kalman 方差证明真实唤醒度可信”，因为模型错设、弱标签与窗口相关性都会破坏该解释。不写“凸组合保证闭环稳定”，因为控制输出有界与系统稳定是不同命题。不写“日志显示下降，因此音乐造成放松”，因为自然恢复、任务结束、呼吸与期望效应均可能解释变化。不写“实时性为 50 ms”，因为该数字只是当前单模型软超时配置。

更合适的表述是：“我们提出并评估一个具有显式失效语义的层级协调框架”；“在定义的故障模型和实验条件下，报告非法执行率、控制性能与时延”；“在预先规定的人体研究条件下，估计相对于对照的变化及其置信区间”。每项主张均对应一个可检查的实验或证明。

# 03 系统对象、变量与问题形式化

## 3.1 用户动力学与观测模型

令 i 表示受试者，s 表示会话，k 表示控制事件，b 表示音乐边界事件。用户的真实状态 x 包含唤醒、疲劳、呼吸及其他未建模因素；实际可观测的是 EDA、RR 等信号 y。音乐引擎执行的是向量 p，PI 输出 u 则是用于生成音乐候选的抽象调控意图。u 与 p 不能混为同一物理输入。

**Equation (1)**

```text
x_(i,k+1) = f_(i)(x_(i,k), p^(exec)_(i)(t_(k)-τ_(i,k)), w_(i,k); Δt_(k))
y_(i,k) = h_(i)(x_(i,k), c_(i,k)) + ν_(i,k)
```

其中 τ 表示以秒为单位的有效反应延迟，p^exec(t) 按最近确认的音乐执行状态作零阶保持，w 表示外部扰动，c 表示传感接触与运动条件，ν 表示测量噪声。式 (1) 是研究用的一般近似，不表示现有代码已识别出 f 或 h；如需反映完整延迟历史，f 的输入应扩展为音乐历史片段。音乐影响方向、强度和延迟都可能因人、曲目与会话而改变；“降低速度就降低唤醒”只能是待检验的局部假设。

控制器通过历史观测构建估计 â∈[0,1]，该值是归一化的唤醒代理，不是直接测得的生理真值，也不是临床量表。参考 r∈[0,1] 表示希望系统追踪的代理水平。参数边界、归一化方式与参考含义需要同时固定，否则不同版本的误差不可比较。

## 3.2 一个异步混合系统

完整运行状态至少包括用户状态、两条估计链状态、两条 PI 积分状态、参考进度、当前音乐、待执行候选、角色局部状态、epoch 和会话模式。人体动力学在事件之间持续演化；软件数值状态在观测等事件触发时更新，音乐参数在两次确认执行之间保持。离散模式变更在启动、失效、恢复、边界与停止事件触发。单一同步流水线会遗漏主要风险；采样、延迟和通信应作为控制系统的一部分分析 [14]。

**Equation (2)**

```text
S_(k) = (x_(k), â^(B)_(k), â^(L)_(k), P^(B)_(k), P^(L)_(k), I^(B)_(k), I^(L)_(k), ξ_(k), p^(exec)_(k), Q_(k), m_(k), epoch)
S_(k+1) = F_(m(k),e(k))(S_(k), observation, proposals)
```

上标 B、L 分别表示基线和学习分支；ξ 是参考进度；Q 是有界执行队列；m 是会话模式；e(k) 在式 (2) 中表示事件类型，后文控制误差用 ε 表示以避免混淆。x 不可直接读取，其他变量必须能通过软件日志或状态接口追踪。

## 3.3 目标函数与约束

研究设计可用下式描述权衡，但首版运行时不要求在线求解这一整体优化。学习模块分别在有限动作空间内改进局部决策，确定性控制器实现闭环。

**Equation (3)**

```text
J = E[ w_(e) Σ_(k) Δt_(k)(a^(eval)_(k)-r^(eval)_(k))^(2)
       + w_(p) Σ_(b) ‖Δp^(exec)_(b)‖^(2)_(W) + w_(h)T_(hold) - w_(v)V ]
subject to: p^(exec) ∈ P, |Δp^(exec)| ≤ Δ_(allowed), permission / timing / mode constraints
```

跟踪项按时间积分，音乐变化项只在已确认音乐边界 b 求和，不乘控制事件的 Δt。W 按各通道预定范围归一化，不能把 BPM 与无量纲参数直接相加。a^eval 与 r^eval 是独立冻结的评估状态与参考；V 是预先定义的偏好或体验指标；T_hold 是不可调节时间。把 hold 纳入评价是为了防止系统通过永远不执行来取得“零非法动作”。权重只用于明确分析目标，若未校准，不应给出看似精确的综合分数。

| 符号 | 解释 | 可观测性 / 来源 |
| --- | --- | --- |
| x, a | 真实系统状态及其唤醒分量 | 通常潜在，不直接可得 |
| y, z, mask | 原始信号、特征、缺失掩码 | 传感器与 L0 |
| â, P, C, q | 状态估计、方差、观测置信、可靠度（工程降额因子） | 估计器与确定性门控 |
| r, θ, ξ | 当前参考、轨迹参数、下降进度 | C2 与规划器 |
| u, Kp, Ki, I | 控制意图、增益与积分状态 | 双 PI |
| c_j | 模块 j 自报置信，不同模块不可互换 | 各 Agent 工件约定 |
| p^prop, p^acc, p^tgt, p^bnd, p^exec | 原始建议、接纳候选、绝对目标、边界投影、实际执行 | 分别记录，ACK 后才更新 p^exec |
| λ, cap, valid | 混合权重、权限上限、有效性 | 模块仲裁与协调器 |
| t_obs, t_dec, t_exec | 观测、决策、执行时刻 | 单调时间域及同步记录 |

# 04 层级组织、权限与状态所有权

## 4.1 三层组织与一条独立执行通路

C0 管理会话的允许范围；C1-C3 管理感知、规划和控制领域；A1-A5 只完成各自的数值任务。C0 不位于每条数据消息的必经路径，因此其管理负担不会自动叠加到每次 PI 运算上。冻结守卫、执行网关和停止通路位于建议树之外，它们执行共同约束。

| 角色 | 输入 / 有限内部状态 | 输出与唯一职责 |
| --- | --- | --- |
| C0 Session Supervisor | 协议、研究臂、版本清单、模式、预算 | 固定会话权限，状态迁移与隔离决定 |
| C1 Perception Coordinator | 观测窗口、质量、两条估计、分支状态 | 唯一已接纳的 StateSnapshot |
| C2 Planning Coordinator | 首个有效锚点、轨迹锁存、进度 | 至多一次参数尝试；持续生成 r |
| C3 Control Coordinator | 同源状态/参考、双 PI、候选和预算 | 有界控制意图与待提交音乐候选 |
| A1 Quality Agent | 信号摘要与缺失/运动/时钟证据 | 质量报告、原因码、观测置信上限 |
| A2 State Agent | 支持的特征历史、学习滤波状态 | 学习估计、方差、适用性与版本 |
| A3 Trajectory Agent | 会话前上下文、批准历史摘要 | 有限轨迹动作与原始采样概率 |
| A4 Gain Agent | 有效状态、误差、参考阶段、历史摘要 | Kp、Ki、死区、泄漏率建议 |
| A5 Preference Agent | 控制兼容候选、偏好摘要、候选 ID | 候选排序及其有效性证据 |

## 4.2 状态归属比角色命名更重要

C2 是“本会话是否已尝试 A3”的逻辑权威写入者，A3 不得自行清除锁存；本轮职责在同一 Session 进程内组织，非独立协调服务。C1 拥有状态快照提交权，但不改写两条滤波器的私有内部状态。C3 分别维护基线与增益 PI，不能将两路积分合并后声称仍有独立回退。执行网关独占音乐写接口，并以引擎确认更新 p^exec。这样可避免两个模块同时声称自己掌握“当前状态”。

局部状态不是无界记忆。A4 只保留当前建议和适用区间；A5 只保留当前候选集与版本；跨会话历史是有数据版本与用途限制的结构化摘要。模型不会通过自由文本记忆偷偷获得其他研究臂结果，也不会在会话内隐式更新权重。

## 4.3 权限只能向下收紧

**Equation (4)**

```text
λ^(eff)_(j,k) = valid_(j,k) · min(λ^(module)_(j,k), cap^(session)_(j), cap^(domain)_(j,k))
0 ≤ λ^(eff)_(j,k) ≤ λ^(module)_(j,k) ≤ 1
```

j 分别表示状态、轨迹、增益或偏好门控。valid 为确定性布尔量，由研究臂、版本、时效、校准、上下文和执行模式共同决定；cap 是预先批准的上限。式 (4) 为 v2.1 规范，具体实现与测试覆盖以修订验收清单为准。某模块 OOD 或失效时，有效性归零；任何上级不得靠“总体效果不错”重开其权限。

模式切换同样受约束。shadow 记录建议但不执行，restricted 仅在批准范围内执行，suggest 可要求指定确认。会话运行时不能自动升级部署权限。可靠度恢复后，在原有批准权限内恢复调控，和学习模块被整场隔离后重新上线，是不同事件。

## 4.4 模块仲裁权重如何产生

现有 arbiter 在结构、版本、上下文、超时、分布内标记与校准检查通过后，再检查状态可靠度 q 和该模块报告的置信指标 c_j。c_j 与状态观测置信 C 不是同一个字段，也不能跨模块解释为统一概率。门控使用进入阈值 q_on、退出阈值 q_off 形成滞回，要求 q_off<q_on<q_full；未激活模块需要更高可靠度才能进入。

**Equation (4a)**

```text
λ_(raw) = clip[(q-q_(off))/(q_(full)-q_(off)), 0, 1] · (c_(j)-c_(min))/(1-c_(min))
d_(j) = ‖a^(prop)_(j)-a^(base)_(j)‖_(W_j)
λ_(module) = min(λ_(raw), δ_(res)/max(d_(j), ε_(d))), in restricted mode
```

式 (4a) 只在 q 已通过当前滞回阈值且 c_j>c_min 时使用；否则权重归零。建议与基线分歧过大而模块置信不足时也直接拒绝。shadow 或未确认的 suggest 不执行学习输出。参数向量和音乐向量的仲裁使用各自定义的归一化距离，不把不同物理量的差直接相加。ε_d>0 避免零分歧除零；对连续凸混合，λ·d_j≤δ_res 的含义是混合结果相对基线的归一化偏离上限。随后施加式 (4) 的层级权限上限，并记录每类拒绝原因。离散分支选择不能通过一个小 λ 部分采用学习分支：A2 采用第 6 章的整分支接纳规则。

**Equation (4b)**

```text
λ^(app)_(j,k) = min(λ^(eff)_(j,k), λ^(app)_(j,k-1) + γ_(j)Δt_(k))
λ^(app)_(j,0) = 0 ; γ_(j) ≥ 0
```

升权按有效事件间隔限速，降权立即；失效时 λ_eff=0，不能继续沿斜坡保留权限。长暂停期间推进计时游标，恢复不补算整段空缺时间。该斜坡用于连续控制/候选混合；A3 会话单次选择不施加跨多事件斜坡，否则唯一尝试将恒为零权重，轨迹变化由确定性规划器限制。A2 默认分支选择使用滞回与整分支批准，不能把渐进 λ 写成分支权重又声称 w∈{0,1}。斜坡限制权重变化，不保证增益突变、分支跳变或生理输出无跳变。

# 05 生理信号、A1 质量判断与时间语义

## 5.1 输入变量的科学含义

EDA 提供皮肤电活动变化，RR 序列用于提取心搏间期相关特征。它们与自主神经活动有关，但并不唯一确定情绪、压力或睡眠。运动、温度、姿势、呼吸、接触变化与药物等因素可能改变观测。本文只将这些特征用于任务限定的唤醒代理估计，必须通过独立标签与实验设计评估其效度。

当前配置包含 10 s EDA 窗口、2 s 更新，60 s HRV 窗口、15 s 更新。这些是现有软件配置，不是通用测量标准。更新步长小于窗口意味着相邻观测强相关。60 s HRV 特征的可用性依赖具体指标与任务，不能把短窗频域特征默认等同于标准短时记录结果 [10,11]。

## 5.2 A1 的确定性输出

A1 检查时间戳是否单调、样本是否完整、RR 是否在设定范围、缺失比例是否超限、运动和接触条件是否合格。输出除等级外，还应包含各项原始指标、缺失掩码、窗口起止时间、原因码和观测置信上限。学习模型可补充质量判断，但不能提高硬规则已限制的质量上限。

个体标准化应基于预先获得的静息基线或允许的历史数据。测试会话的未来数据不能参与均值与方差估计；若做在线基线自适应，必须将更新过程作为算法的一部分重新评估，不能一边移动基线一边宣称唤醒度下降。

**Equation (5)**

```text
z_(i,j,k) = (f_(i,j,k) - μ_(i,j)) / max(σ_(i,j), ε_(σ))
age_(k) = t_(now) - t_(obs,end) ; duration_(k) = t_(obs,end) - t_(obs,start)
```

μ、σ 的来源、估计范围与冻结日期须记录。窗口结束时间决定新鲜度，窗口长度决定信息覆盖范围；两者缺一不可。将旧状态复制到新消息时不能重置原始观测时间。不同设备时钟的偏差和漂移需要测量，壁钟用于人类审计，过期判断使用单调时间或明确的跨设备同步方案。

## 5.3 双 TTL 与适用性分开

**Equation (5b)**

```text
fresh_(j)(t) = [0 ≤ t-t^(obs)_(end) ≤ TTL^(obs)_(j)]
                    ∧ [0 ≤ t-t^(dec) ≤ TTL^(proc)_(j)]
```

观测 TTL 从原始来源窗口结束计时，处理 TTL 从该建议决策时刻计时；不得在排队、缓存、复用或重发时重置。t_dec 不早于输入 available_at；未来时间戳、非有限时刻和时间回退直接拒绝。目标规范要求多模态各有原始 window ID 与结束时间，按每个必需模态检查 TTL，而非取最新 EDA 时间掩盖陈旧 HRV；本轮实现只具备 RawWindow 整体 observed_end_t，逐模态历史快照与 TTL 尚待适配层完成。所有 TTL、时钟映射与复用域在会话前冻结。

新鲜度只保证年龄合格。误差符号、阶段、候选集、父 ACK 或权限发生变化时，即使两类 TTL 未到也可能不再适用；式 (17) 独立检查 applicable。

## 5.4 跨模态对齐与信息重复

同一 RR 窗口若被多个 2 s 快事件重复使用，不代表获得了多条独立 HRV 证据。首版应明确分离快 EDA 与慢完整状态事件，并记录每个特征的 source_window_id。学习状态模型只能在其工件声明支持的历史节拍上启用。若训练仅覆盖完整慢窗，实际混合快慢更新会改变后验递推，必须重新校准。

对于丢失模态，应使用训练时验证过的缺失处理或直接回退，不能默默将缺失值当作真实零值。插值可以用于某些信号预处理，但插补结果必须保留标志；质量判定不能因插补后数组长度完整就改判为高质量。

# 06 A2 状态 Agent：估计、校准与独立回退

## 6.1 两条估计链为何都保留

基线估计器提供可解释的固定发射关系与滤波；学习分支由 A2 提供数据驱动的观测映射，并维护另一套滤波状态。两条链使用相同原始观察时具有相关误差；独立的是代码状态与失效隔离，不是统计独立。学习分支失效时，不能复用其已受污染的后验作为基线初值。

学习发射可表示为 m=g_φ(z, mask)，其观测方差 R_φ 应表达与训练任务一致的残差尺度，而非任意“模型信心”。当前项目采用紧凑的高斯发射模型，未来可比较线性模型与小型 MLP，但升级必须说明数据规模、参数量与校准改善，不能只凭模型更复杂。

**Equation (6)**

```text
L_(emit)(φ) = Σ_(n) [ (y_(n) - μ_(φ)(z_(n)))^(2) / (2R_(φ)(z_(n))) + 0.5 log R_(φ)(z_(n)) ] + η‖φ‖^(2)
R_(φ) ≥ R_(min) > 0
```

y_n 是带来源说明的监督训练标签，可以是自评或任务代理；它不等于潜在真实唤醒。训练集用于拟合 φ，独立校准集用于校准误差尺度。式 (6) 是可选的异方差训练形式，不表示现有实现已经包含该训练头。若使用固定残差方差，则需报告其估计方式和对不同质量分组的表现。

## 6.2 与现有递推一致的滤波表达

对 j∈{B,L}，使用标量随机游走近似：

**Equation (7)**

```text
P^(j,-)_(k) = P^(j)_(k-1) + Q^(j) · s_(k)
K^(j)_(k) = P^(j,-)_(k) / (P^(j,-)_(k) + R^(j)_(k))
â^(j)_(k) = â^(j)_(k-1) + K^(j)_(k)(m^(j)_(k) - â^(j)_(k-1))
P^(j)_(k) = (1 - K^(j)_(k))P^(j,-)_(k)
```

s_k 是与工件验证一致的过程噪声时间尺度，不可将 2 s 与 15 s 更新当作相同一步。缺失时仍应传播不确定性，不能保持旧方差造成伪确定。以上滤波方程的理想统计解释依赖模型假设；重叠窗口、弱标签、个体漂移均要求在完整时间序列上验证后验覆盖。

## 6.3 主方法采用分支选择，连续融合保留为对照

可对点估计作有界混合，但方差不能简单套用“两个独立高斯融合”。设 w 为通过模块门控后的学习权重，e_B、e_L 是相对同一参考真值的误差。对固定 w，或在包含权重选择信息的条件下，若误差均值为零且边际误差方差已有效校准，则：

**Equation (8)**

```text
â = (1 - w)â^(B) + wâ^(L)
Var(e) = (1 - w)^(2)P^(B) + w^(2)P^(L) + 2w(1 - w)Cov(e_(B), e_(L))
Var(e) ≤ [(1 - w)√P^(B) + w√P^(L)]^(2)
```

v2.1 主方法固定 w∈{0,1}。学习分支仅在血缘、双 TTL、工件校准、更新节拍、整分支权限与滞回条件全部满足时被采用；否则使用有效基线，无有效基线则 HOLD。接纳输出的均值、P、C 和分支 ID 来自同一分支。分支选择降低了连续融合的解释负担，但数据依赖选择本身仍可能改变条件覆盖，必须对“接纳后序列”再次报告经验校准。restricted 若不允许完整采用分支，则保持基线。

最后一式使用 Cauchy-Schwarz 界，前提是 P 真正界定相应误差尺度；它不能修复系统偏差或失效校准。连续混合与下文启发式只作为独立命名的对照，不能和默认分支选择的结果混报。若使用 covariance intersection，需要另立算法和验证，不应在本文中冒称已实现。

## 6.4 校准应覆盖完整闭环输入历史

至少分别报告点误差、负对数似然、预测区间覆盖率、区间宽度、按质量与受试者分组的误差，以及误差随观测年龄变化的曲线。区间覆盖必须明确针对弱标签、滤波后标签还是潜在变量；如果没有真实潜在标签，不能报告对真实唤醒的覆盖率。

训练、校准与测试按受试者和时间拆分。重叠窗不得跨集合；特征缩放、缺失补全和基线估计只用允许的数据。分类温度缩放 [7] 可说明“模型输出需要校准”的一般动机，但不能直接作为连续滤波状态已校准的依据。连续回归校准工作 [8] 与该任务更相关，仍需在实际时序与分布条件下另行验证；数据漂移下的评估尤其不能省略 [12]。

## 6.5 当前高斯发射的具体形式

为便于复现，现有 LearnedGaussianEmission 可以展开为特征的条件高斯模型。令 z 为经过个体标准化与方向统一的特征，b 为截距，B 为响应斜率向量，Σ_0 为校准前正则化残差协方差，Σ_cal 为工件最终存储的协方差：

**Equation (6a)**

```text
z | a ∼ N(b + B(a - 0.5), Σ_(cal))
J_(0) = B^(T)Σ^(-1)_(0)B ; v = Σ^(-1)_(0)B / J_(0)
m = clip(0.5 + v^(T)(z-b), 0, 1) ; R = s_(cal)/J_(0) ; Σ_(cal) = s_(cal)Σ_(0)
```

s_cal 来自独立校准，J_0 是校准前标量信息量；需要正则化或约束以避免奇异残差协方差和信息量过小。若从工件的 Σ_cal 计算信息量 J_cal，则 R=1/J_cal，不能再次乘 s_cal。由该发射得到的 m、R 再进入式 (7)，不会在融合后额外串联第二个 Kalman。随机游走先验不是已识别的音乐-人体响应动力学。

现有学习分支在合格完整观测下的 confidence=1.0 主要是可用性/质量标记，不能解释为“预测百分之百正确”。工件中的 ECE 对应多个中央区间的经验覆盖偏差，论文宜明确定义为 central-interval calibration error：CICE=(1/|A|)Σ_q |coverage(q)-q|，避免与分类分箱 ECE 混淆。最低样本阈值是软件接纳条件，不是充分统计证据。

## 6.6 旧连续融合变体的准确定位

v2.0 连续融合变体在 w=0 时直接返回基线状态，即 P_accepted=P^B、C_accepted=C^B。只有在 w>0 时对均值作门控混合，并采用下式抑制方差被不当缩小：

**Equation (6b)**

```text
P_(heuristic) = max(P^(B), P^(L)) + w(1-w)(â^(L)-â^(B))^(2)
C_(accepted) = min(C^(B), C^(L))
```

这是保守的工程启发式，不是已经证明校准的融合后验。式 (8) 的理论误差界需要固定权重，或在包含权重选择信息的条件下拥有有效的边际误差界；数据依赖的门控选择不能被忽略。两条链内部 P 若不代表真实误差尺度，取 max 也不能自动建立真实误差上界。论文应比较分支选择、当前启发式与经验证的融合方案，并报告不确定性对门控和控制的实际影响。

# 07 A3 轨迹 Agent：会话级有限决策

## 7.1 为什么只决策一次

目标轨迹决定用户需要追踪什么。如果高频控制器同时不断改变目标，系统可以通过把目标移向当前状态来降低误差，而不真正改善生理结果。首版因此将轨迹参数选择限制在首次有效锚定机会：先由 C2 写入“已尝试”锁存，再调用 A3；无论成功、超时或被拒绝，都不重新选择。失败时固定默认轨迹。

锁存拥有明确生命周期。未获得可用初始状态时可以继续等待锚定；一旦达到可锚定条件并开始尝试，失败不能被解释成“还没试过”。进程重启也不能在同一会话重置锁存，应通过持久化记录或创建新 epoch 并执行恢复协议处理。

## 7.2 动作空间与统计层级

轨迹参数 θ=(δ_anchor,T_match,T_descent,r_floor,g_speed)，分别控制初始偏移、匹配时长、下降时长、目标下限与进度速度系数。A3 从经批准的有限轨迹集合中选动作，或输出严格有界参数；首版优先采用有限候选，便于审计概率与覆盖支持。研究臂、硬安全阈值和会话权限不在动作空间中。

群体与个体部分池化可用以下研究模型说明：

**Equation (9)**

```text
E[R | c, a, i] = φ(c,a)^(T)β + φ(c,a)^(T)b_(i) ; b_(i) ∼ N(0, Σ_(b))
π(a | c,i) = exp(v(c,a,i)/τ) / Σ_(a'∈A(c)) exp(v(c,a',i)/τ)
```

c 只包含选择前可获得的上下文与允许的历史摘要；R 是预先定义的会话结局；个体数据不足时应收缩到群体估计。式 (9) 给出可研究的统计形式，不等价于声称当前 bandit 已实现完整贝叶斯后验。温度、随机种子、候选集合和各动作概率必须保存。会话内权重冻结，策略更新在会话外进行。

## 7.3 参数固定与参考自适应并不矛盾

匹配阶段参考保持在锚点；下降阶段由确定性进度 ξ 生成参考。状态可靠且跟踪较好时进度推进，可靠度不足时可暂停。参数 θ 不变，变化的是规则定义的进度状态。

**Equation (10)**

```text
r_(anchor) = clip(â_(0) + δ_(anchor), r_(min), r_(max))
r_(goal) = min(r_(anchor), r_(floor))
ξ_(k+1) = clip(ξ_(k) + Δt^(active)_(k) v_(k)/T_(descent), 0, 1)
r_(k) = r_(anchor) + (r_(goal) - r_(anchor))ξ_(k) ; 0 ≤ v_(k) ≤ v_(max)
```

â_0 是首次有效锚定所接纳的状态；δ_anchor 的单位与状态相同；r_min、r_max 与偏移允许范围由协议冻结。若睡前协议要求锚点也不得主动抬升，须额外冻结 δ_anchor≤0 或对应裁剪规则；r_goal≤r_anchor 本身只保证锚定后的参考非增。v_k 是可靠度与跟踪滞后的确定性函数。对睡眠导向下降方案，若初始状态已经低于设定下限，不应为了匹配模板主动抬高目标。Δt^active 只计算允许推进阶段的实际时间，不能把长时间暂停后的间隔一次性补成巨大下降。

## 7.4 奖励与离线评估的边界

若奖励直接使用模型自己的状态和自己的参考，A3 可以偏好更容易追踪的轨迹，得到虚假的性能改进。应将独立评估状态、预先规定的终点、偏好、不可用时间和任务完成情况分开报告。权重在数据分析前固定，并对不同权重做敏感性分析。

原始动作采样概率并不一定是最后锁定轨迹的概率。门控、混合、默认替换或取整可能将多个原始动作映射到同一执行动作。在完全已知的离散映射 g 下，执行概率须对所有前像求和；上下文缺失、确定性行为或支持不足时，不能凭一条 logprob 直接做可靠的 IPS/DR 推断 [9]。

# 08 A4 增益 Agent 与可靠度调节的双 PI

## 8.1 控制误差与可靠度

控制误差定义为 ε=r-â。正向控制意图在当前规则映射中倾向提高音乐速度与部分复杂度，负向倾向降低；这是映射约定，不是对每个用户反应方向的保证。A4 只能给出 Kp、Ki、死区 δ 与积分泄漏 ρ，不能修改输出硬限、积分硬限或可靠度阈值。

**Equation (11)**

```text
ε_(k) = r_(k) - â_(k)
q_(k) = C_(k) · clip[(P_(hard) - P_(k))/(P_(hard) - P_(soft)), 0, 1]
P_(hard) > P_(soft) ≥ 0 ; 0 ≤ C_(k), q_(k) ≤ 1
```

P、P_soft、P_hard 必须属于相同的方差量纲。C 与 P 可能来自相关证据，q 是工程降额因子，不是概率意义上的“动作安全概率”。阈值来源与敏感性必须报告，不能让 A4 在运行中调整阈值来提高自己的可用率。

## 8.2 保留旧递推，明确 v2.1 控制变体

令 j∈{B,L}。式 (12) 描述 v2.0 兼容变体：泄漏用于无可靠状态、死区或暂停，正常激活积分不逐步泄漏。v2.1 的式 (12b) 作为显式配置的变体，不能静默替换旧工件参数。

**Equation (12)**

```text
I^(j)_(k) = ρ^(j)_(k)I^(j)_(k-1),  if q_(k)≈0 or |ε_(k)| &lt; δ^(j)_(k)
I^(j)_(k) = clip(I^(j)_(k-1) + q_(k)ε_(k)Δt_(k), -I_(max), I_(max)), otherwise
u^(j)_(k) = 0, if inactive; otherwise clip[q_(k)(Kp^(j)_(k)ε_(k) + Ki^(j)_(k)I^(j)_(k)), -u_(max), u_(max)]
```

无可靠状态时 u=0 的数值本身不足以定义整个系统行为，必须另带 HOLD 原因，令音乐层保持完整当前向量并撤销待执行变化。可靠状态下的死区则可以走另一个既定规则。不能把两种语义都归结为相同的“零控制量”。

旧式 q 同时乘积分增量与输出，本步积分对输出的贡献为 q²KiεΔt，比例项仅有一次 q。该耦合不是公式错误，但改变低可靠度时 P/I 相对权重，需与条件积分独立消融。按秒累积与按事件泄漏也使 Imax 和衰减速度依赖实现节拍。

**Equation (12b)**

```text
Δt̃_(k) = Δt_(k)/T_(I) ; ρ_(k) = exp(-Δt_(k)/τ_(I))
I^(j)_(k) = clip(I^(j)_(k-1) + ε_(k)Δt̃_(k), -I_(max), I_(max)), active ∧ q_(k)≥q_(on)
I^(j)_(k) = I^(j)_(k-1), active ∧ 0&lt;q_(k)&lt;q_(on)
I^(j)_(k) = ρ_(k)I^(j)_(k-1), q_(k)=0 or deadband or suspend
ΔI^(j)_(ack) = (Δt_(ack)/T_(t))(u_(ack)-u_(cmd))/(q_(cmd) Ki^(j)_(cmd)), valid attributable ACK
```

active 表示处于可调节模式且误差在死区外；代码以冻结的小正阈值处理有效 q≈0，近零情形进入失效泄漏分支。T_I>0 是参考时间常数；τ_I>0 控制暂停/死区时的按时间泄漏，正常积分时不额外泄漏；T_t>0 是以秒为单位的反算时间常数。附件定义 ρ(Δt) 但未明确其适用分支，本实现规范延续旧控制器的泄漏分支，仅将每事件系数改为时间函数。Ki_norm=Ki_legacy·T_I，I_norm=I_legacy/T_I，Imax 同比例迁移，只做归一化可保持积分贡献；去除积分侧 q、条件积分、按时间泄漏和 ACK 反算分别作为消融因素。

ACK 反算仅适用于已定义逆映射且能归因到单一 PI 分支的速度通道：u_ack=(tempo_ack-tempo_parent_ack)/12，u_cmd 是同一命令的映射前意图。输出侧含 qKi，反算分母相应为 q_cmd·Ki_cmd；参数与时间段均取匹配命令历史。每个 ACK 以 command ID 至多消费一次，补偿后再做积分硬限。缺失/重复/跨 epoch ACK、未知执行状态、Ki≤ε_K、q≤ε_q、通道无逆映射或两路输出混合不可单独归因时，反算为零；不把一个总执行误差重复灌入两路积分。

**Equation (13)**

```text
u_(k) = (1 - λ^(app)_(gain,k))u^(B)_(k) + λ^(app)_(gain,k)u^(L)_(k)
```

两路 PI 对同一已接纳状态和参考计算，各自保留积分历史。学习路失效时 λ=0，基线路保持可用；如果观测本身失效，两路都不能假装有有效反馈。恢复后的无扰切换、建议变化速度与积分状态处理，需要在故障与延迟实验中验证。

## 8.3 增益训练与控制可接受域

A4 可用线性回归作为首版，并与小型 MLP 对照。标签应来自独立的控制器搜索、受约束仿真优化或明确的专家方案，不能把“该会话奖励高”直接当作四个增益的真值。训练可最小化归一化参数误差，但模型评价最终还需检查闭环误差、振荡、饱和占比与噪声敏感性。

**Equation (14)**

```text
K̂(c) = project_(K_allowed)(Wφ(c)+b)
L_(gain) = Σ_(n,j) [(K̂_(n,j)-K*_(n,j))/(K_(j,max)-K_(j,min))]^(2) + η‖W‖^(2)
```

式 (14) 为拟议的归一化损失比较方案；现有 GainPolicy.fit 使用原始参数空间的岭回归闭式解，裁剪作用于预测输出。K_allowed 首版是冻结参数盒；它限制参数取值，但不是已证明稳定的增益域。论文若要声称“稳定域内调节”，必须先对指定动力学、延迟范围及切换规则得到稳定性证据，再将允许集合替换成经认证的集合。

## 8.4 增益变化与工件迁移

增益突变即使在误差不变时也会改变输出。可比较冻结增益变化率 |K_k-K_(k-1)|≤κ_KΔt 与低频更新；权重斜坡不能替代增益变化检查。A4 的 Ki 和泄漏参数必须绑定 controller_variant、T_I 与 τ_I；旧模型预测值不能直接交给重新归一化的积分器。

控制量 u 是父决策上的调控意图，不是直接施加给人体的输入。它先生成第 9 章的固定绝对音乐目标，经边界投影、引擎 ACK 后才进入响应模型。两路积分的死区、暂停和泄漏历史不同，式 (13) 一般不等价于单个 PI 的增益插值。

# 09 A5 偏好 Agent、音乐约束与动作语义

## 9.1 先保证控制兼容，再进行偏好选择

音乐参数 p 包含速度、力度、明亮度、节奏重音、混响以及离散声部。规则映射先由 u 与实际当前音乐产生候选，并定义允许方向与变化量。A5 只在这个候选集中排序，不得通过偏好把下降意图改为上升，也不能修改参考 r。

**Equation (15)**

```text
C_(k) = {p : p∈P, direction(p,p^(exec),u_(k)) valid, grammar(p) valid}
p*_(k) = argmax_(p∈C_k) s_(ψ)(context_(k),p)
```

如果没有充分证据建立生理响应模型，direction 只能表示音乐参数与规则控制意图相容，不能称为保证生理下降。候选集必须有 ID、生成版本与父控制决策 ID。即使偏好建议的 TTL 未过期，当控制方向、候选集或实际当前音乐改变时也要重新验证。

## 9.2 绝对目标、父 ACK 与重传幂等

**Equation (15b)**

```text
p^(tgt)_(k) = p^(ack)_(parent(k)) + Δp(u_(k))
tempo^(tgt)_(k) = tempo^(ack)_(parent(k)) + 12u_(k)
```

生成目标时固定 parent_ack_id 与完整已确认向量；目标此后不随当前音乐自动重新计算。同通道只保存按来源血缘排序最新且仍适用的目标，新目标覆盖旧目标，不能按迟到结果的到达顺序让旧决策覆盖新决策。跨通道有联合约束时以一个原子目标组提交，避免拼出从未通过守卫的混合向量。

需区分两个性质：同一 command ID 的重传不能再次应用；尚未完成的固定 target ID 可在后续真实边界通过新的 command ID 继续逼近同一绝对目标，但每次均重验双 TTL、适用性与预算。绝对目标防止重复加增量，不意味着多边界投影后的状态始终等于第一次部分执行的状态。父 ACK 血缘用于解释目标来源，当前 ACK 用于边界再投影；ACK 状态未知时暂停生成新目标。

## 9.3 偏好训练与缺失反馈

可使用喜欢程度回归、二元反馈或成对排序。成对数据足够时，可比较 logistic 排序损失 L=Σ log(1+exp(-(s(p^+)-s(p^-))))。跳过歌曲不必然意味着不喜欢，可能是任务结束、注意力变化或实验指令；未反馈也不能当作负例。需记录反馈来源、暴露时长、呈现顺序与候选曝光策略。

偏好提升和调控效果是两项不同结局。高偏好音乐可能唤起记忆并增加唤醒；单纯最大化偏好不等于更好地追踪目标。论文应展示两者的权衡，以及规则候选是否过窄而牺牲个体化。

## 9.4 投影、响度硬约束与实现边界

连续参数可作加权投影：

**Equation (16)**

```text
p^(bnd)_(b) = argmin_(p∈P(p_ack,boundary)) ‖p-p^(tgt)‖^(2)_(W)
```

声部层级等离散变量由显式合法转移规则处理，不对类别编号或 bitmask 做连续平均。约束集合依赖当时实际音乐与真实小节/乐句边界，所以提交时要再次投影。若投影让偏好建议退化为不同参数，需要单独记录 proposed、accepted、target、projected 和 executed，不能把偏好模型原评分直接当作执行动作的评分。

当前速度约束按照距上次已应用变速的时间累计变化预算，首次变化还存在初始化预算；它不是连续导数界，也不严格等价于任意滚动时间窗内的最大变化。其他连续参数主要受取值范围和边界规则约束，不能写成所有音乐维度都有统一变化率限制。若希望加入预算上限或逐维变化率约束，应作为新的实现与实验项目。

当信号无效时，保持的是整个音乐向量，而不是只冻结速度、同时让音色恢复另一默认值。正常模式下可以有确定性的小节变化；保持模式下应撤销所有未经确认的待执行变化。连续 HOLD 时长由 T_hold,max 限制，超时转 STOPPING。

响度保护为与模型无关的硬约束，研究臂共享绝对上限及变化率上限。当前公开数据/仿真可以验证数字力度或增益代理的取值与速率，但 MIDI velocity、归一化 gain 均不能直接写为耳边声压级。真实声压需要设备链路、输出端测量与校准；未完成时应明确“声学限值尚未验证”，不宣称软件幅值限幅已保证听觉安全。被拦截的越界候选计入 rejected_unsafe_attempts；只有提交发生时违反约束才计 invalid_commits，ACK 后实际越界另计 acknowledged_limit_violations。

# 10 异步通信、执行网关与停止语义

## 10.1 三类消息与四种时间

Snapshot 描述发生了什么；AgentProposal 描述建议做什么；AcceptedDecision 与 ExecutedAction 分别表示被接纳和已执行。消息应不可变，包含父 ID 和内容哈希。不可变并不意味着分布式事务自动正确，仍需唯一写入者、顺序规则和幂等处理。

| 消息 | 必须包含的字段 | 用途 |
| --- | --- | --- |
| ObservationSnapshot | epoch、seq、window IDs、t_start/end、features、quality | 防止重包装旧观测 |
| StateSnapshot | parent observation、估计/方差/质量、分支版本、门控结果 | 唯一控制状态依据 |
| AgentProposal | parent IDs、agent/model/calibration、payload、validity、latency | 可拒绝、有限期的建议 |
| AcceptedDecision | 参考/控制/候选血缘、父 ACK、权重、原因、绝对目标 | 明确软件决策责任 |
| ExecutedAction | command ID、boundary ID、engine ack、实际参数/时间 | 作为下一周期的真实执行依据 |

t_obs 是观测时间；t_dec 是建议产生时间；t_submit 是发送时间；t_ack 是引擎确认时间。新鲜度遵循式 (5b)，观测 TTL 与处理 TTL 不互相替代。对于迟到的完整状态，系统可选择丢弃或采用事先验证的延迟估计方法，但不能按当前无延迟观测直接进入滤波。

## 10.2 建议被执行的必要条件

**Equation (17)**

```text
accept = epoch_match ∧ version_match ∧ lineage_match ∧ fresh
             ∧ context_applicable ∧ permission_valid ∧ quality_valid
commit = accept_rechecked ∧ boundary_valid ∧ lease_valid ∧ ¬stop_latched
```

“还没过期”和“仍适用”是不同条件。A4 的增益可在限定状态范围复用，但误差符号、阶段或研究权限改变时可能立即失效。A5 的候选身份必须与当前候选集一致。A2 状态输出通常要求与当前观测血缘匹配，不能用旧状态建议覆盖更新的状态。

执行队列应有界，同一控制通道优先保存最新仍适用的目标候选；旧增量不得在多个音乐边界依次补交。对重发 command ID 应保证幂等，或由引擎查询确认实际状态。若引擎不支持确认，报告中只能称“已发送”，不能称“已执行”。

## 10.3 正常流程与独立停止

[英文执行时序图见排版 PDF](pdf/MDT-v2.2-research-dossier.pdf)

正常流程可由 C1、C2、C3 组织，但停止路径必须能直接撤销执行许可。停止与提交存在竞态，需要定义线性化点：在最终许可检查与提交的原子步骤中，若停止先发生，该候选不得提交；若命令已发送，则进入取消/停止并等待执行侧反馈的流程。软件接收停止并不等于音频瞬间静音。

停止延迟需分别测量命令接收、锁存、队列撤销、引擎停止确认与实际音频输出结束。独立 watchdog 不能依赖可能被模型阻塞的同一线程；实现可选择独立进程或设备侧机制，但需要实测故障路径。本轮实现状态与已完成测试见修订验收清单；软件 STOP 测试不能替代真实设备音频终止测量。

## 10.4 总周期预算

**Equation (18)**

```text
T_(decision) = CP_(G)(T_(feature), T_(state), T_(planning), T_(control), T_(preference), T_(gate))
T_(effect) = T_(decision) + T_(queue) + T_(boundary) + T_(engine)
```

CP_G 是冻结依赖图 G 上的最长依赖路径：串行取和、并行分支取最大。本轮 critical_path_seconds 计算给定 DAG 的理想 makespan，假设并行资源充足，不自动包含调度、队列或引擎成本；实际时延仍需事件测量并显式加入这些节点/等待，不能把理想路径计算冒充端到端测量。A3 只在锚定时运行；A4/A5 可按预算跳过。单模型 50 ms 是当前软超时配置，Python 线程超时不等于底层计算被终止。部署需限制并发、资源与超时后生命周期，防止失效模型持续占用 CPU。

需要同时报告 P50/P95/P99 决策时延、最大观测年龄、边界等待分布、超时率与不可用时间。这里的“实时”是满足任务定义的时间条件；未经调度与设备证明，不使用“硬实时保证”。

# 11 失效模式、降级状态机与恢复

## 11.1 三种行为不能混淆

**Fallback：** 学习建议不可用，但基线观测与控制仍有效，使用确定性基线。**Hold：** 缺乏可靠状态，取消待执行变化并维持确认过的完整音乐向量。**Stop：** 用户停止、许可撤销或约定故障条件触发后，终止继续调节并执行设备停止流程。Fallback 不是所有故障的通用答案；Hold 也不是无限期播放的安全证明。

会话模式为 INITIALIZING、BASELINE、LEARNING_ENABLED、DEGRADED、HOLD、STOPPING、STOPPED。每次迁移记录触发证据、单调时间与 manifest。有效基线建立后 INITIALIZING→BASELINE；整分支权限和滞回满足才进入 LEARNING_ENABLED。模块失效而基线可用时 DEGRADED；任一活动模式丢失可靠状态即 HOLD。规范要求 HOLD 恢复取得足够有效历史，先回 BASELINE，再评估已批准学习权限；当前实现用冻结 recovery_observations 计数，若研究要求持续 T_rec 秒还需加驻留时间验证。整场隔离的模块不随信号恢复自动重启。

[英文运行状态机见排版 PDF](pdf/MDT-v2.2-research-dossier.pdf)

T_hold,max 必须为有限正值且会话前冻结；连续 HOLD 计时不能被重复低质量包、模型心跳或重发目标重置。超时由独立计时事件触发 STOPPING，即使无新生理消息也必须触发。用户 STOP、许可撤销或协议故障可从任一未停止模式触发 STOPPING；STOPPED 为本会话终态。引擎停止确认与实际音频终止是两个证据字段，仿真中只报告模拟确认，不能伪装硬件测量。

| 故障 | 必须采取的动作 | 恢复条件 / 验证点 |
| --- | --- | --- |
| A2 超时、校准不符、历史不支持 | 隔离学习滤波，保留有效基线 | 不使用受污染学习后验初始化基线 |
| A3 首次失败 | 锁定默认参数，消费本次尝试机会 | 本会话不得重试以挑选有利结果 |
| A4 失败或建议过期 | λ_gain=0，使用有效基线 PI | 各自积分状态保持明确定义 |
| A5 失效或方向冲突 | 回到规则候选，仍经过守卫 | 不重放失效候选 |
| 无可靠状态 / 时间错乱 | 撤销待执行变化，进入 HOLD | 有效观察恢复后回 BASELINE；超过 T_hold,max 则 STOPPING |
| 引擎无确认 / 状态未知 | 不更新 p_exec；冻结后续累积 | 查询状态或执行停止恢复协议 |
| 协调器失联 | 新学习建议不接纳，许可到期 | 基线独立有效则降级，否则 HOLD/STOP |
| 停止与边界同时发生 | 按原子许可顺序决定提交/撤销 | 实际停止延迟、残留音频与命令幂等 |
| 响度或数字代理越界 | 拒绝候选，记录被拦截尝试 | 分开统计尝试、非法提交、已确认越界 |

## 11.2 故障模型必须与保证范围一致

若所有模块共用一个进程，进程崩溃会同时影响协调器与软件守卫；此时只能依赖设备侧行为或独立 watchdog。若音频引擎可能忽略停止指令，软件无能力单独保证停止完成。论文必须写清可信计算边界，包括操作系统调度、时钟、引擎接口与硬件输出的假设。

对恶意输入与普通故障也应区分。本方案首先处理延迟、缺失、非法值、异常返回与并发竞态，不自动构成针对攻击者的安全协议。模型参数哈希帮助版本一致性和审计；没有签名与信任链时，不应称为防篡改证明。

## 11.3 可用性与约束遵守共同评价

一个永远 HOLD 的系统可能从不违反执行约束，却没有调节价值。因此报告必须同时呈现 valid-control coverage、fallback/hold 比例、任务完成、恢复时间与非法提交率。比较故障条件下的性能时，要报告总时长分母；只在“系统成功控制”的时段计算误差会产生选择偏差。

# 12 理论分析：哪些能证明，哪些还不能

## 12.1 可以先证明的软件不变量

命题 A：在 λ_module、cap_session、cap_domain 均处于 [0,1] 且 valid 为布尔量时，式 (4) 不增加模块学习权限；式 (4b) 进一步满足 λ_app≤λ_eff。证明直接来自 min 的上界与非负性。该命题只证明权限关系，不证明任何生理结局。

命题 B：若两路 PI 输出均在 [-u_max,u_max]，且混合权重在 [0,1]，则混合控制也在同一区间。证明由区间凸性成立。但输入有界不推出状态收敛，也不保证系统不会持续振荡。

命题 C：若执行接口只有一个写入者，提交检查与停止锁存拥有定义明确的原子顺序，且引擎按命令协议工作，那么停止锁存先于提交线性化点发生的候选将被拒绝。证明需要代码级或状态机级检查；对于已发送命令，仍要分析执行侧取消与音频停止。

命题 D：若 C2 以原子“先锁存再调用”方式持久化每个会话的尝试标识，且所有入口都检查该标识，则 A3 每个会话至多尝试一次。进程重启、请求重放和多线程必须包含在证明假设或测试覆盖中。

命题 E：固定父 ACK 生成绝对目标，且引擎按 command ID 去重时，同一命令重传不产生新增状态变化。不同 boundary 的新命令可继续逼近同一目标，不属于重传；因此不能将“目标不重复累积”和“一次部分投影后永不变化”混为同一命题。

## 12.2 参考轨迹的条件性质

在 r_goal≤r_anchor、v_k≥0 且 ξ∈[0,1] 时，式 (10) 的参考非增并有界。若长期有足够有效推进时间，参考可达到 r_goal；若可靠度长期为零，则只能保证暂停，不能保证有限时间完成。参考单调也不意味着用户状态单调，更不意味着情绪改善。

## 12.3 闭环稳定性分析需要识别对象

为了开展局部分析，可先识别一个近似模型 δa_{k+1}=αδa_k+βδp_{k-d}+w_k，并把音乐参数执行状态、PI 积分、采样间隔与延迟缓冲组成增广状态 z。该模型只是研究分析工具，必须在独立数据上检验预测误差和参数范围。尤其 β 可能因人或情境而变号，此时固定控制方向不能保证负反馈。

**Equation (19)**

```text
z_(k+1) = A_(cl)(θ_(user), K_(k), λ_(k), Δt_(k), d_(k), mode_(k))z_(k) + B_(w)w_(k)
A^(T)_(cl)HA_(cl) - H ≼ -Q ; H ≻ 0, Q ≻ 0
```

如果能对所声明的不确定性、延迟、增益与模式集合找到共同 H，则可在该离散模型和适用范围内建立统一二次 Lyapunov 性质，LMI 提供相应分析工具 [15]。当前尚未识别该集合，也未求解该条件。只在若干采样增益上发现谱半径小于 1，不等于任意时间变化或切换都稳定；若采用不同 Lyapunov 函数，还需驻留时间等额外条件。

严格衰减条件首先针对固定参考附近的有效调节模式。HOLD 中音乐状态保持，可能出现单位特征值，因此不能要求所有保持/停止模式都严格收敛到同一原点；需采用非增条件或独立模式性质，并另行限制切换及停留。扰动 w 应包含估计误差与参考增量，移动参考的跟踪不能直接引用零输入稳定性。式中 d_k 若使用离散延迟步数，须由具体增广模型定义，与式 (1) 的秒单位 τ 区分。

## 12.4 饱和、偏好与音乐边界为何增加难度

控制器输出到音乐之间有饱和、限速、离散层级、候选排序、音乐边界延迟和可能的命令合并。对“PI 直接控制唤醒”的简化模型得到的结论，不自动覆盖真实执行系统。可以按阶段分析：先研究固定方向、固定延迟的局部线性模型；再加入限幅与抗积分饱和；最后加入切换、候选和边界，报告每一步适用域。

积分硬限和可靠度降额只限制数值行为。v2.1 的条件积分与 ACK 反算按式 (12b) 定义，仅在可确认、可归因的执行通道生效；这不构成对全部音乐通道的 anti-windup 或闭环稳定性证明。

## 12.5 最合适的理论主张层级

当前可完成的第一层是软件不变量及其测试；第二层是经过识别的局部模型上的条件分析；第三层是在仿真族与硬件回放中的鲁棒性证据；第四层是人体研究中的效应估计。四层证据相互补充，不能用某一层替代另一层。若最后只有前两层，论文应定位为方法/系统研究，而不是有效干预的临床结论。

## 14.2 仿真不是给结论造数据

构建多类可解释响应模型，覆盖正向、零响应、反向、时变敏感度、非线性饱和、延迟、基线漂移、呼吸/运动干扰与异方差噪声。参数范围若来自真实数据，应报告识别集；若为压力测试，应明确标注为人工范围。训练用仿真族与测试用仿真族分离，以免控制器只学会对付自己的训练环境。

对同一个模拟受试者、外部扰动和随机种子运行配对系统，报告跨虚拟受试者的分布。不要仅挑三条好看的示例曲线。对反向响应，应观察检测、失效模式和停止策略；若系统无法辨认，应如实报告该失效域。

B1 不是“把 H 的防护关闭”。先由未接触 F3 结果的实现者按书面 common-practice 规格实现合理的异步处理、超时、时间戳和状态管理，记录角色、接触信息、版本哈希与冻结时间；再开展独立评阅。现实常见的 ACK、去重与取消逻辑可以且应保留。若 B1 已满足某项契约，该项没有对比差异，应如实报告并改为隔离消融研究。

公平矩阵固定模型与训练数据、输入来源、音乐候选、硬守卫、停止能力、计算预算、调参预算和评价规则。各臂共用独立观测器，记录命令、真实执行与相同时间基准，但不将审计专用信息反馈给控制策略。不能因 B1 没有 MDT 内部字段而直接判为非法；字段不足先标未知，实际违规必须按共同的输出、时间和权限规则判定。

规格先冻结，故障结果后公开，外部评阅最后记录。当前状态为 planned / not independently reviewed；本轮 AI 分工不构成独立工程师或外部评阅完成证明。针对 epoch、TTL、ACK 等逐项关闭的实验继续保留，明确属于 F3 契约消融，不冒充强 B1。

# 15 指标、独立评估与统计设计

## 15.1 防止“改变尺子”得到漂亮结果

如果 A2 改变状态估计，A3 又改变参考轨迹，直接比较各系统自己的 |â-r| 会把估计差异和目标难度混入控制效果。必须配置独立冻结评估器 a^eval 和公共评价协议；在有模拟真值时使用真值，在人体中明确使用自评、预先规定的生理摘要或其他外部参照。

轨迹追踪误差可以保留作为工程指标，但应同时报告相对共同固定参考的误差、最终状态变化、目标完成进度、可靠覆盖率和体验。目标较温和的系统跟踪容易，不一定更有效；保持时间多的系统输出平滑，也不一定更有价值。

**Equation (20)**

```text
RMSE_(time) = √[ Σ_(k) Δt_(k)(a^(eval)_(k)-r^(eval)_(k))^(2) / Σ_(k) Δt_(k) ]
TV_(music) = Σ_(b) ‖W(p^(exec)_(b)-p^(exec)_(b-1))‖_(1)
Coverage = valid_control_time / scheduled_session_time
ViolationRate = invalid_commits / commit_opportunities
```

W 将不同音乐参数归一化到可比较尺度；离散声部另报告转移次数。commit_opportunities 的定义在实验前固定，并同时给 invalid_commits 的绝对数量及以实际提交数为分母的违规比例。缺失观测造成的不可评估时段单独报告，不用删除后变小的分母掩盖问题。若人体评价只有稀疏自评，式 (20) 应改为对应时点的有限和，不插值制造连续生理真值。

## 15.2 当前研究的主要估计对象

采用 estimand 的五属性结构明确研究问题；这是分析框架借鉴，不把模拟研究称为临床试验。本轮只执行公开数据与仿真，不要求人体数据采集。

| 属性 | 当前系统机制研究 |
| --- | --- |
| 目标总体 | 预先固定抽样分布中的虚拟配置及故障场景；不是人群风险 |
| 条件 | B2 对 B1 为主；H 对 B2 为层级的探索性比较；相同模型与硬限 |
| 终点 | 每个独立配置在规定种子和场景集合内是否至少发生一次非法提交 |
| 并发事件 | STOP、HOLD 超时、ACK 丢失、崩溃均保留；未知执行状态单列，并报告最坏情形敏感性分析 |
| 汇总 | 配置级事件率差/适用时率比及区间；覆盖、完整时长控制误差与 P99 作为必报权衡 |

不变量违反、被拒绝越界候选、已发生非法提交、ACK 后越界为四类事件，分别统计。不能用被拦截尝试替代非法提交，不能把无法确认的执行状态默认为无事件。仿真在算法停止后仍按共同评估时长推进虚拟对象，使用预定停止后输入策略评分，防止删掉困难时间段。

公开感知任务的独立估计对象是“未见真实参与者上 A2 相对固定映射的参与者平均误差变化”；不是同一 estimand，也不与配置级事件率合并。非主要指标明确标记为次要或探索性，避免结果出来后挑选最显著者。

## 15.3 非劣效与代价边界

H1 的主要控制代价定义为 D_RMSE=RMSE_B2-RMSE_B1，正值表示契约实现较差。ΔNI 必须在最终测试前，根据独立试运行尺度与任务允许损失确定；单侧 95% 区间上限低于 ΔNI 才支持该界值下非劣。coverage 损失定义为 Coverage_B1-Coverage_B2，时延代价为 P99_B2-P99_B1，分别冻结界值与方向。E_hier 的 RMSE_H-RMSE_B2 另行作为探索性比较，不替代主比较。

预定多个必要条件时明确联合通过规则和主要比较族；常规双侧差异不显著不证明非劣。若界值没有依据，报告效应与区间，不填写任意数字来保证通过。检验失败可能是精度不足；只有区间支持超过界值的损失，才有证据称为劣效。

## 15.4 未来人体研究的估计对象与设计

未来研究另行冻结五属性：符合审定纳排条件的人群；随机分配 H 对 B0；预定时段的单一主观唤醒或睡眠结局；STOP/失效后的结局采集策略及退出处理；条件间平均差与区间。具体量表、临床重要差异和纳排标准由获批方案确定。本轮没有人体结局，不填结果或真实样本量。

若干预效应短暂且可合理洗脱，可考虑随机交叉设计，平衡条件顺序并建模 period/order；若存在学习、习惯或持续效应，应考虑平行设计或更长洗脱，而不是假设交叉自动更高效。音乐偏好、音量、环境、姿势、时段和呼吸相关行为尽量标准化并记录。

至少需要确定性闭环对照，以检验个体化学习的增益。若要证明反馈本身的作用，可另设预录或 yoked 对照，但其音乐暴露分布、时长和体验尽可能匹配。原有研究臂与新增架构消融属于不同实验因素，不应随意合并。算法不能重新分配研究臂。

不能完全盲化听觉体验时，可使数据分析者在预先冻结流程下盲于条件编码，并统一向受试者提供中性说明。中止、退出和信号失效会造成选择性缺失，需要保留分配信息，报告按分配分析与符合方案分析的差异。

预先定义中止等研究事件及其后的结局采集方式。若主要估计对象是按随机分配使用整套系统的效果，应在可行且获准时继续采集停止干预后的结局；停止本身及原因另作为系统结果。未获得的结局不能直接删除或默认为成功。主分析说明缺失机制假设，并对与状态或条件相关的缺失开展敏感性分析；符合方案分析作为补充。

## 15.5 聚类结构与统计模型

窗口不是独立受试者。真实公开数据按参与者、仿真按独立虚拟配置聚类；同配置种子先聚合或显式建模。未来人体实验首选会话级预定义摘要，或使用与数据层级匹配的混合效应模型。示意模型如下：

**Equation (21)**

```text
Y_(i,s) = β_(0) + β_(1)Condition_(i,s) + β_(2)Baseline_(i,s) + β_(3)Period_(i,s) + b_(i) + ε_(i,s)
```

b_i 是受试者随机截距；是否需要随机斜率、序列相关或异方差结构取决于设计和样本支持。时序模型不能通过加入数万个窗口把几个受试者变成大样本。置信区间与 bootstrap 应以受试者或适当聚类层级为单位。报告效应大小、区间和不确定性，不能只报告 p 值。

## 15.6 样本量与零事件结果

先指定最小有意义差异、方差、受试者内相关、失访率与主要比较，再基于先导数据或合理外部证据模拟功效。简单配对近似 n≈[(z_(1-α/2)+z_(1-β))σ_d/δ]^2 只适用于相应简化条件，不能替代交叉/混合模型仿真；本文不给出没有数据依据的受试者数量。

**Equation (21b)**

```text
p^(95%)_(upper) = 1-0.05^(1/n)
n_(min)(p_(0)) = ceil[ln(0.05)/ln(1-p_(0))]
```

公式只适用于定义明确、独立同分布的 Bernoulli 单位，且 n 次均无事件。本轮 zero_event_session_risk_upper_bound API 的参数名为 independent_sessions；在本方案中调用方须先以独立配置汇总规定测试集，不可把相关种子会话数直接传入。p0=1% 至少 299 个独立单位；p0=0.5% 至少 598 个。若同一虚拟配置跑 5 个种子，应按“该配置的规定测试有无事件”计一个单位，不能把相关会话数扩大五倍；200 个独立配置零事件的单侧上界约 1.49%。场景分布、重复次数变化会改变该配置级事件定义，不能直接互比。固定参数网格不是随机抽样，只给测试范围与计数。零事件普通 bootstrap 的 [0,0] 不是有效风险上界。

## 15.7 M0 的分母、未知状态和区间

每类事件先确定风险集。例如 STOP 竞态以存在 STOP 机会的会话为风险集；没有该机会的会话是 not_at_risk，不充当无事件证据。风险集内以 confirmed、ruled_out、indeterminate 三态记录；同会话同类事件去重，重复消息不能扩大分母。报告 N_eligible、N_at_risk、N_assessable、N_unknown、N_event 和可判定覆盖率。主率 N_event/N_assessable 只代表可判定风险集，不能无条件代表所有会话。

若风险集 N 中有 E 个确定事件和 U 个未知，会话实际事件比例只被限定在 [E/N,(E+U)/N]；这是缺失状态的逻辑范围，不是置信区间。无样本或全未知时不得写成 0%。只有完整可判定、预定义且独立同分布的 Bernoulli 单位才直接使用精确二项区间；多会话参与者、部署或相关配置应采用聚类分析，不能因软件能计算就忽略相关性。

M0 的四种事件分别需要：源观测时间与执行确认以判断过期执行；意图/目标/父 ACK 与边界序列以判断重复增量累积；STOP 线性化及执行顺序以判断竞态；完整确认流与软件前移证据以判断无 ACK 的状态误判。合法逐步逼近绝对目标、被正确拒绝的旧建议、合法硬守卫裁剪均不计为失败。单纯缺少 ACK 首先是执行未知，不证明执行或未执行。

多事件阈值和检验族须预先声明；工具逐事件给出的单侧 95% 界不是全族同时 95% 结论。稀有事件是否高后果还需独立严重性证据，不由低频或高强度 F3 构造推出。

# 16 离线策略评估与因果解释

## 16.1 闭环日志为什么有偏

系统根据历史状态选择音乐，音乐又改变后续状态，因此上下文、动作和结局形成反馈。对某个参数与 HRV 做简单相关，不能分离选择偏差与动作作用；控制器可能正因为用户状态不好才给出更强动作，从而使“强动作与差结果相关”。

A3 是会话级一次决策，较适合在完整记录的上下文、动作支持和行为策略前提下研究 contextual bandit 评估。A4/A5 则为多次序贯决策，不能把所有时刻当成相互独立的会话 bandit 样本。仅比较模型在历史状态上“会建议什么”，也不能知道建议执行后的反事实生理轨迹。

## 16.2 原始概率与执行概率

**Equation (22)**

```text
μ_(exec)(a_(e)|c) = Σ_(a:g(c,a)=a_e) μ_(raw)(a|c)
V̂_(IPS)(π) = (1/N)Σ_(n) [π(a_(n)|c_(n))/μ(a_(n)|c_(n))]R_(n)
```

第一式只适用于已知且完整记录的离散映射；若输出是连续混合、存在未记录的人工覆盖、历史相关门控或未观测的候选变化，则需要更完整的概率模型。第二式要求动作定义一致、支持覆盖、正确倾向概率以及相应可识别性假设 [9]。裁剪权重会引入偏差；有效样本量与裁剪敏感性必须报告。

Doubly robust 方法结合奖励模型与重要性权重，但不会修复无动作支持或未记录混杂。历史行为若几乎总选择默认轨迹，数据不足以比较未出现轨迹；此时最诚实的结论是“现有日志不支持可信策略价值估计”，而不是输出一个看似精确的提升百分比。软件回放也不同于利用随机日志估计策略价值 [13]。

另一个不同的估计对象是“选择某原始提案并通过固定下游执行链”的策略价值。在定义清楚该干预、固定下游控制与音乐策略、正确记录提案概率并满足识别条件时，原始概率可以用于提案层评估；该结果不能改称为某个实际音乐动作的因果效果。跨会话更换下游模块后，原估计对象已经改变。

## 16.3 Shadow 证据与前瞻证据

shadow 可以验证推理时延、版本与血缘、建议合法性、门控频率和潜在冲突，不能测量建议真正作用后的用户效果。已执行策略产生的观察也不是未执行策略的未来观察。论文中应将 shadow 结果列为系统验证，不写成干预优越性证据。

如果目标是因果比较个体化控制与基线闭环，最清晰的主要证据是前瞻随机分配并记录实际实施情况。离线评估用于筛选和补充，而不是代替需要的实验。本文给出分析路线，不声称当前项目已经具备充分数据和支持条件。

# 21 执行算子下的离线策略评估：条件候选路线

## 21.1 先承认已知结果，再界定剩余问题

静态确定性执行映射把多个提议粗化为同一执行动作，属于 MIPS 的动作嵌入特例 [19]。OffCEM 以簇级权重结合残差模型，在局部正确性条件下处理簇内回报差异 [20]。一维裁剪分布的内部密度、端点原子和 Radon-Nikodym 重要性权重已在混合测度 OPE 中明确讨论 [28]；CAPG 也利用裁剪结构改进策略梯度 [21]。无重叠时基于 Lipschitz 条件的尖锐部分识别与收敛率已有研究 [27]。因此不能把这些事实本身列作新算法或新定理。

候选问题聚焦版本化、历史相关的执行机制：算子更新造成奇异支持迁移，内部状态更新规则改变可重建历史，ACK 缺失使物理执行部分不可观测。能否形成论文三，取决于特定结构带来的可证明额外信息、可计算估计量或效率增量；当前状态为 conditional candidate，未通过新颖性决策门。

## 21.2 从完整历史和物理执行核开始

令 H_t 为提议前完整可用历史，包括观测时间、已确认与未决命令、门控、边界、预算和故障状态。a_t 是提议，e_t 是完整物理执行描述，含参数、开始时间、持续时长以及是否真正执行；K_v 是版本 v 的执行核。已知软件投影不必等于已知物理执行。

**Equation (23)**

```text
a_(t) ~ π(da | H_(t)),  e_(t) ~ K_(v)(de | H_(t), a_(t))
π̄_(v)(de | H_(t)) = ∫ K_(v)(de | H_(t), a) π(da | H_(t))
```

确定性算子是点质量核的特例。若用有限状态 s_t 取代历史，须明确其对策略、奖励和转移的充分性假设；记录若干执行字段不会自动获得 Markov 性。唯一写入者只限制软件旁路，不能证明提议没有直接回报或未来状态作用。推理耗时、投影惩罚、拒绝成本、PI 内部状态和预算恢复均可能保留提议的影响；此时应扩大执行描述、保留原始动作或明确残差模型。

## 21.3 固定算子：原始 IPS 与执行 IPS 都可能有效

本节的式(24)先限于离散动作/执行、共同上下文分布及跨策略不变的奖励核；连续或混合测度使用式(25)。上下文分布变化时须另行正确重加权。对于单步 contextual bandit，若日志和目标使用相同执行机制，行为概率正确且原始动作绝对连续，原始提议 IPS 可以无偏估计通过该机制部署的策略价值。它并非一律错误。若给定上下文和完整执行后，奖励与被粗化提议条件独立，执行权重可构成相应 Rao-Blackwell 化，有限二阶矩下提供方差比较 [19]。

**Equation (24)**

```text
E_(μ)[π(a | x)/μ(a | x) | x,e] = π̄(e | x)/μ̄(e | x)
V = E_(μ)[(π(a | x)/μ(a | x)) R]
  = E_(μ̄)[(π̄(e | x)/μ̄(e | x)) R]
```

这些是带条件的已知恒等式，不是本项目新成果。只有执行覆盖而没有原始覆盖时，执行评估仍可能有效，但不能再用原始 IPS 的有效性作同条件方差对照。估计权重、截断、SNIPS 与序贯乘积不自动继承静态 oracle 定理。DR 也不能修复未支持动作或未记录混杂 [9,24]。

## 21.4 Q1 优先：算子变化与绝对连续性

对算子从 log 版改为 target 版，权重必须由相应诱导执行测度定义。普通 IS 要求绝对连续，拓扑支持包含不够。跨版本给定历史与完整物理执行后的奖励核须相同；版本自身改变耗时成本或反馈测量时，不能只用执行动作权重迁移价值。

**Equation (25)**

```text
w(H,e) = dπ̄_(target)(· | H) / dμ̄_(log)(· | H) (e)
π̄_(target)(· | H) ≪ μ̄_(log)(· | H)
```

例：原始动作在 [-2,2] 均匀分布，日志 clip 到 [-1,1]，目标 clip 到 [-0.5,0.5]。目标在 ±0.5 各有 0.375 的点质量，日志在这两个单点的质量为 0，尽管日志在那里有连续密度 0.25。目标拓扑支持包含于日志支持，却不绝对连续。不能拿连续密度去除端点质量；合计 0.75 的目标奇异质量不支持普通 IS。

若单步目标测度分为可识别的绝对连续部分与奇异部分，后者质量 α，奖励界 [L,U]，则有下列基础界：

**Equation (26)**

```text
V ∈ [V_(ac) + αL, V_(ac) + αU]
```

这是已知的缺失质量界，不是新定理，也不是有限样本置信区间。增加连续或 Lipschitz 假设后，新边界位于旧连续区域内部时，可能通过邻域极限识别其奖励；这属于平滑识别与估计，应与 [27] 比较，不能继续称作原子 IS。新的问题必须给出执行结构带来的额外约束、尖锐性或可计算增量。

序贯扩展还需相同或可加权的初始分布、跨版本不变的物理转移/奖励以及历史覆盖。若版本改变预算或门控状态更新，日志内部状态不是目标内部状态；只有能从共同物理历史重建目标状态时，才可形成正确目标条件概率。单步奇异质量不能直接代入累计回报界，须在轨迹或首次失去覆盖层面处理。

ACK 缺失不意味着未执行，也不意味着维持最后确认动作。负载相关本身既不证明 MAR 也不证明 MNAR；完整案例分析会改变被评估负载分布。缺乏可识别假设时报告不可识别，使用明确参数的敏感性分析；模型插补不得冒充物理真值。

等价类内部改变提议分布而不改变执行分布，本来就可能不改变价值。裁剪的样本路径导数为零，不意味着尾部总概率对策略参数的梯度为零；不能据此预先断言学习必然停滞。

## 21.6 最小实验和独立立项门

先完成离散 bandit 与一维裁剪，交叉测试同算子、只改策略、只改算子、策略/算子同时变化。加入新边界奇异质量、隐藏状态遗漏、提议直接成本、ACK 缺失与权重估计误差反例。基线包括 oracle 原始 IPS、oracle 执行 IPS/MIPS、估计权重、DM、DR 和适用的现有平滑部分识别方法。精确概率与估计概率分开报告。

除偏差、MSE 外，报告奇异质量、权重二阶矩、支持失败率、区间覆盖和宽度。ESS 是诊断量，不是可识别性或覆盖保证。最小枚举检查仅验证式(24)和裁剪反例，其输出明确标记 constructed_mathematical_sanity_check，不计入 M0/F1，不作为新算法性能结果。

若扩展到 Safety Gymnasium 等公开环境，应重新采集含行为策略概率、算子版本、原始/执行动作和真实转移的模拟日志 [26]。不能事后裁剪 D4RL 的动作却沿用原始奖励及下一状态 [25]，那会伪造不存在的反事实转移。现有 MDT 公开生理记录缺少对应音乐干预概率和可识别回报，不能支撑 OPE 主验证。

立项通过需同时满足：明确的新问题与识别条件；与 [19,20,27,28] 的逐项区别；非平凡理论或算法增量；可复现的反例和适用边界；相同数据预算下与强基线比较。若仍只能复现已知边缘化或基础界，将本章收为论文一的局限与未来工作，不强拆成第三篇论文。

## A.2 真实音乐边界与人工停止

```text
Algorithm 2: v2.1 execution boundary
1  Receive a real bar/phrase event with boundary_id.
2  Read latest pending decision and acknowledged engine state.
3  Reject if epoch, either TTL, lineage, candidate, mode or lease fails.
4  Re-project against actual current music and boundary limits.
5  At the atomic commit point: recheck STOP and permission.
6  Submit absolute parameters with idempotent command_id; await/query ACK.
7  Record actual parameters/time only on ACK; consume matched ACK once

8  On unknown execution state: freeze accumulation and recover/stop.

Independent STOP entry:
1  Latch STOP; revoke lease; invalidate pending work for the epoch.
2  Cancel queued commands and invoke execution-side stop.

4  Reject all late model results; never resume without a new protocol.
```

原子提交点需要系统实现与引擎协议共同定义。若只有“检查完再调用函数”而无互斥或版本化原子语义，检查与执行之间仍可能被停止事件穿插。独立停止的验收包括竞态测试和设备输出测量。

# D 附录：一次完整闭环的数值演示

## D.1 演示条件与两路控制

以下全部数字是为核对运算而构造的教学示例，不是推荐参数、仿真结果或受试者数据。假定该会话已经允许学习，A3 在此前锚定时完成参数锁存，本轮不会再次调用它。当前有效估计 â=0.70，参考 r=0.50，可靠度 q=0.80，距上次有效控制事件 15 s，误差为 -0.20，位于两路死区之外。

设基线积分上一步为 -0.10，学习路为 -0.20，本例积分硬限大于 2.6，因此积分不会被裁剪。基线增益取 Kp=0.45、Ki=0.015；本轮 A4 的合法建议为 Kp=0.55、Ki=0.020。仅为本例，假定其他门控均通过，混合权重为 0.30，输出不会触及硬限。

**Equation (D1)**

```text
ΔI = qεΔt = 0.80 × (-0.20) × 15 = -2.40
I^(B) = -2.50 ; I^(L) = -2.60
u^(B) = 0.80[0.45 × (-0.20) + 0.015 × (-2.50)] = -0.10200
u^(L) = 0.80[0.55 × (-0.20) + 0.020 × (-2.60)] = -0.12960
u = 0.70 × (-0.10200) + 0.30 × (-0.12960) = -0.11028
```

## D.3 从建议到实际音乐

假定父决策绑定的 ACK 速度为 70 BPM，固定 target_id 的绝对目标为 70+12u=68.67664 BPM。A5 在控制兼容候选中选择一项；为只展示执行逻辑，本例设其没有改变这个期望速度。到真实边界时，假设当时允许的速度变化预算只有 0.80 BPM，因此最终提交速度为 69.20 BPM。

68.67664 是期望值，69.20 是约束后的提交值；只有引擎确认实际应用 69.20，才能将其写入 p^exec。如果引擎最终报告其他值或没有确认，后续控制必须按事实处理。同一 command_id 重传只返回原执行事实；后续边界可在仍新鲜且适用时创建新命令继续接近固定 68.67664，不在新的 69.20 上再次加 12u。这个投影例子区分目标、提交和确认；仿真 ACK 不等于真实听觉暴露。

| 顺序 | 事件 | 关键状态 |
| --- | --- | --- |
| 1 | 观测窗口结束并通过质量检查 | 建立 ObservationSnapshot，保留原始时间 |
| 2 | C1 提交状态，C2 生成 r | A3 锁存已存在，不重复选择 |
| 3 | A4 被接纳，双 PI 计算 | u=-0.11028，来源快照一致 |
| 4 | A5 选择候选，静态校验入队 | 保留期望速度 68.67664 及候选身份 |
| 5 | 真实边界到达，重新验证 | 根据当时预算投影为 69.20 |
| 6 | 引擎确认执行 | ExecutedAction 记录 69.20 与实际时间 |

## D.4 同一个流程中的异常

若 A4 在截止时间前没有返回，当前轮采用有效基线 u=-0.10200；不等待迟到结果，也不在下一边界补执行它。若候选到达真实边界时任一 TTL 已过期，即使期望速度合理也应丢弃；新建议必须重新基于有效状态形成。若下一观测显示传感器脱落，系统撤销队列并保持完整 p^exec，不把 A5 的失败处理误用为恢复默认音色；持续超过 T_hold,max 转 STOPPING，不等待下一观测。

若用户随后发出 STOP，系统撤销许可并调用执行侧停止，测量确认与实际音频终止延迟。这个例子只能验证运算和消息语义，不能由 -0.11028 或 69.20 推断用户唤醒会降低多少；该关系必须通过动力学识别与实际研究建立。
